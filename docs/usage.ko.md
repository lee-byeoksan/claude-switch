# Claude 계정 메뉴 사용 안내

macOS 메뉴 막대에서 Claude Desktop의 데이터 폴더를 프로필 단위로 바꿔 계정을 전환하는 앱입니다.
Claude.app은 하나만 설치하고 원본을 수정하지 않습니다.

## 동작 원리

- Claude는 `~/Library/Application Support/Claude`를 데이터 폴더로 사용합니다.
- 이 앱은 그 경로를 symlink로 바꾸고, 링크 대상을 프로필 폴더로 전환합니다.
- 프로필 폴더는 `~/Library/Application Support/ClaudeProfiles/profiles/<이름-id>/`에 있습니다.
- 로그인 토큰과 쿠키는 데이터 폴더 안에 있고, 암호화 키는 키체인의 "Claude Safe Storage" 항목 하나를 모든 프로필이 공유합니다. 이 앱은 키체인을 읽거나 쓰지 않습니다.
- 전환할 때마다 Claude에 정상 종료를 요청하고, 관련 프로세스가 모두 사라진 것을 확인한 뒤에만 링크를 바꾸고 Claude를 다시 실행합니다. 강제 종료는 하지 않습니다.

## 설치와 실행

1. `scripts/build.sh --install`을 실행하면 `~/Applications/ClaudeSwitch.app`에 설치되고 서비스 메뉴가 등록된 뒤 실행됩니다. 직접 복사할 때는 `~/Applications` 또는 `/Applications`에 두어야 서비스 메뉴가 등록됩니다.
2. 처음 열 때 Gatekeeper 경고가 나오면 Finder에서 우클릭 후 "열기"를 선택합니다. ad-hoc 서명이라 이 절차가 필요합니다.
3. 같은 앱을 두 곳에 두고 번갈아 실행하면 서비스 메뉴가 엉뚱한 복사본을 가리킬 수 있습니다. 설치본 하나만 실행하세요.

## 세 가지 진입점

| 진입점 | 언제 | 내용 |
|---|---|---|
| 프로필 선택 창 | 런처 시작 시 Claude가 꺼져 있을 때, 런처를 다시 열 때, 서비스 메뉴에서 | Active/Inactive 탭, 프로필별 작업 아이콘, 새 프로필, 설정 |
| Claude 메뉴 > 서비스 > "Claude Switch" | Claude가 앞에 있을 때만 표시 | 선택 창을 띄움. 시스템 설정 > 키보드 > 단축키 > 서비스에서 단축키 지정 가능 |
| 메뉴 막대 아이콘 | 설정에서 켠 경우 | 기존 전체 메뉴 |

## 선택 창 사용법

프로필 상태는 세 가지입니다.

| 상태 | 뜻 | 데이터 |
|---|---|---|
| Active | 목록에 보이고 전환할 수 있음 | 보관 |
| Inactive | 목록의 Inactive 탭에 흐리게 표시, 전환 불가 | 보관 |
| Removed | 목록에서 제거 | 폴더를 macOS 휴지통으로 이동. 휴지통을 비우기 전까지 Finder에서 복구 가능 |

행마다 있는 아이콘:

- 왼쪽 원: 누르면 그 프로필로 전환합니다. 현재 프로필은 채워진 체크로 표시되고 항상 맨 위에 굵게 나옵니다. Claude가 꺼져 있을 때 현재 프로필의 체크를 누르면 바로 실행합니다.
- 정보(i): 폴더 이름, 만든 날짜, 계정 ID 힌트, 백업 경로를 팝오버로 보여 줍니다.
- 연필: 이름을 그 자리에서 수정합니다. Enter로 저장, Esc로 취소.
- 보관함: Active → Inactive. 되돌리기 화살표: Inactive → Active.
- 휴지통: Removed. 확인 대화상자 뒤 폴더를 휴지통으로 옮깁니다. 현재 프로필은 제거할 수 없습니다.

오른쪽 위 톱니바퀴에서 설정(메뉴 막대 아이콘, 로그인 시 실행, 서비스 단축키)과 고급 항목(되돌리기, 상태 점검, 폴더 열기, Claude 종료 요청, Claude Switch 종료)을 엽니다.

## 설정

- 서비스 메뉴 단축키: 기본값은 Cmd+Ctrl+S입니다. 설정 팝오버의 입력란에 `cmd+ctrl+s`나 `⌘⌃S` 형식으로 넣고 적용하면 macOS의 서비스 단축키 저장소(`pbs` 설정)에 기록됩니다. 시스템 설정 > 키보드 > 단축키 > 서비스에서 바꾼 것과 같은 자리이며, 서비스 단축키는 Claude가 메뉴를 만들 때 읽으므로 실행 중인 Claude에는 재실행 후 반영됩니다. 저장 직후 재실행 여부를 묻습니다. 이 저장 형식은 Apple이 문서화하지 않아 macOS 업데이트로 바뀔 수 있으며, 그 경우 시스템 설정에서 직접 지정하면 됩니다.

- 메뉴 막대 아이콘 표시: 끄면 선택 창과 서비스 메뉴만 사용합니다.
- 로그인 시 런처 실행: 시스템 로그인 항목으로 등록합니다. 시스템 설정의 로그인 항목에서 승인해야 할 수 있습니다. 서비스 메뉴는 상주하지 않아도 동작합니다.

## 현재 프로필 탐지

런처를 거치지 않고 Claude를 실행해도 현재 프로필은 데이터 경로의 링크 대상에서 읽습니다. 계정 ID 힌트는 config.json의 기록입니다.

## 첫 설정: 기존 데이터를 첫 프로필로 등록

1. 메뉴에서 "기존 Claude 데이터를 첫 프로필로 등록…"을 선택합니다.
2. Cowork 작업이 끝났는지 Claude 창에서 직접 확인합니다. 이 앱은 작업 상태를 감지하지 못합니다.
3. 첫 프로필 이름을 입력하면 다음 순서로 진행합니다.
   - Claude 정상 종료 요청과 종료 확인
   - `ClaudeProfiles/backups/Claude-<날짜>`에 백업 복제 생성 (APFS clone이라 즉시 만들어지고 추가 용량이 거의 들지 않음)
   - 데이터 폴더를 프로필 폴더로 이동
   - 원래 경로에 링크 생성
   - Claude 재실행
4. Claude가 다시 실행되면 로그인이 유지되는지, Cowork가 동작하는지 확인합니다.

## 프로필 추가와 전환

- "프로필 추가…"로 빈 프로필을 만듭니다. 바로 전환할지 묻습니다.
- 전환하면 Claude가 로그인 화면을 보여 줍니다. 그 계정으로 직접 로그인하세요.
- 새 프로필은 빈 상태에서 시작하므로 확장 프로그램, 설정, Cowork VM 번들(약 10 GB)을 다시 내려받습니다. 프로필별로 디스크 공간을 고려하세요.
- 메뉴 상단의 프로필 목록에서 이름을 누르면 전환합니다. 현재 프로필은 체크 표시가 붙고 비활성입니다.

## 현재 계정 확인

- 메뉴 첫 줄은 "현재 프로필: 이름"입니다. 이 이름은 사용자가 붙인 라벨일 뿐 실제 로그인 계정을 보장하지 않습니다.
- 둘째 줄에 Claude가 config.json에 기록한 마지막 계정 UUID의 앞 8자리를 표시합니다. 이 값은 Claude가 기록한 참고 정보이며 프로필 이름과 별개입니다.
- 실제 로그인 계정은 Claude 앱 설정에서 확인하세요.

## 이름 변경, 등록 해제, 다시 등록

- "이름 변경"은 표시 이름만 바꾸고 폴더 이름은 유지합니다.
- "등록 해제 (데이터 보관)"는 메뉴에서만 제거합니다. 폴더는 그대로 남습니다. 현재 사용 중인 프로필은 해제할 수 없습니다.
- "보관된 프로필 다시 등록"으로 되돌립니다.
- manifest에 없는 폴더가 `profiles/` 안에 있으면 "미등록 폴더 가져오기"에 나타납니다. 내용은 바꾸지 않습니다.

## 일반 폴더로 되돌리기

"현재 프로필을 일반 Claude 폴더로 되돌리기…"를 선택하면 링크를 제거하고 현재 프로필 폴더를 원래 경로로 옮깁니다.
이후 Claude는 이 앱 없이도 원래처럼 동작합니다. 다른 프로필 폴더는 `ClaudeProfiles`에 남습니다.

## 전환이 거부되는 경우

- Claude 관련 프로세스가 남아 있으면 아무것도 바꾸지 않고 프로세스 목록을 보여 줍니다. Claude 창에 확인 대화상자가 열려 있는지 확인하고 직접 종료한 뒤 다시 시도하세요.
- 데이터 폴더 안의 파일을 열고 있는 프로세스(터미널의 현재 디렉터리 포함)가 있어도 거부합니다.
- 링크 교체 직전이나 직후에 Claude가 다시 실행되면 원래 프로필로 되돌리고 오류를 표시합니다.
- 완료되지 않은 이전 작업 기록이 있으면 "상태 점검"으로 먼저 복구합니다.

## 파일 위치

| 항목 | 경로 |
|---|---|
| Claude 데이터 경로 (링크) | `~/Library/Application Support/Claude` |
| 프로필 폴더 | `~/Library/Application Support/ClaudeProfiles/profiles/` |
| 백업 | `~/Library/Application Support/ClaudeProfiles/backups/` |
| 등록 정보 | `~/Library/Application Support/ClaudeProfiles/manifest.json` |
| 진행 중 작업 기록 | `~/Library/Application Support/ClaudeProfiles/journal.json` |
| 로그 | `~/Library/Application Support/ClaudeProfiles/account-menu.log` |

모든 폴더와 파일은 소유자만 접근할 수 있는 권한(0700 / 0600)으로 만듭니다.

## 진단 명령

```
~/Applications/ClaudeSwitch.app/Contents/MacOS/ClaudeSwitch --scan
```

현재 경로 상태와 Claude 관련 프로세스, 데이터 폴더 파일을 열고 있는 프로세스를 출력합니다.

## 용량 정리

설정 > "용량 정리…"에서 프로필별 점유량과 정리 작업을 볼 수 있습니다.

| 작업 | 대상 | 효과와 조건 |
|---|---|---|
| VM 이미지 복제 | 다른 프로필 전체 | 원본 프로필의 VM 기본 이미지(rootfs, 커널, initrd), 압축 캐시, 해시 마커를 APFS clone으로 복사합니다. 즉시 끝나고 추가 점유가 거의 없으며, 대상 프로필은 Cowork를 켤 때 다운로드를 건너뜁니다. 세션 데이터와 VM 식별자는 복사하지 않습니다. 대상 프로필이 실행 중 rootfs에 쓴 임시 변경은 업데이트 때처럼 초기화됩니다. |
| 자동 복제 | 위와 같음 | 기본 켬. 런처 시작, 10분 주기, Claude 종료 시점에 마커가 다른 프로필이 있으면 조용히 복제합니다. 원본 파일을 열고 있는 프로세스(VM 실행 중)가 있으면 미룹니다. 현재 프로필은 Claude가 꺼져 있을 때만 대상이 됩니다. |
| 캐시 삭제 | 프로필별 | Chromium 캐시(Cache, Code Cache, GPU 캐시)를 지웁니다. Claude가 다시 만듭니다. 현재 프로필은 Claude가 꺼져 있을 때만 가능합니다. |
| VM 이미지 삭제 | 현재가 아닌 프로필 | rootfs, 커널, initrd, 해시 마커를 지웁니다. Claude 자체의 "재설치 파일 삭제"와 같은 범위이며 sessiondata.img는 보존합니다. 압축 캐시를 남기면 다음 업데이트를 delta로 받고, 함께 지우면 전체 다운로드가 됩니다. 자동 복제가 켜져 있으면 지운 뒤 곧 다시 채워지므로, 공간 회수 목적이라면 자동 복제를 끄거나 Inactive 프로필에만 쓰세요. |
| 백업 휴지통 이동 | 첫 등록 백업 | manifest에 기록된 백업만 대상이며 휴지통으로 옮깁니다. clone 백업이라 원본과 갈라진 블록만 회수됩니다. |

원본 프로필은 현재 프로필에 완전한 번들이 있으면 현재 프로필이고, 없으면 마커 파일이 가장 최근에 바뀐 번들입니다. 표시되는 크기는 파일별 할당 블록의 합이라 clone으로 공유된 블록이 중복 계산됩니다. 실제 여유 공간은 Finder나 `df`로 확인하세요.
